# আলোময় সঙ্গীত (Alomoy Songit)

A site for listening to Bengali Islamic and devotional songs, organized
by album.

## What it offers

- Browse and stream songs across a growing library of albums.
- A dedicated player for each album with play/pause, next/previous,
  seek, shuffle, and repeat (all/one/off) controls.
- A full track listing for every album, with one click to jump to any
  song.
- Download the song currently playing.
- Search across the full song library.
